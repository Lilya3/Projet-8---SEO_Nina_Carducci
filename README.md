# Nina Carducci

Projet 7 réalisé dans le cadre de la formation Développeur Web OpenClassrooms.

## Aperçu

Site vitrine d'une photographe professionnelle optimisé pour les performances, le référencement naturel (SEO) et l'accessibilité.

## Objectifs du projet

- Analyser les performances du site
- Identifier les problèmes de SEO
- Améliorer l'accessibilité
- Optimiser les performances Lighthouse
- Réduire le temps de chargement

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Lighthouse
- Schema.org
- Open Graph

## Compétences développées

- Audit de performance
- Optimisation SEO
- Accessibilité web
- Optimisation des images
- Amélioration des Core Web Vitals
- Analyse Lighthouse

## Résultats obtenus

- Amélioration du score Lighthouse
- Optimisation du référencement naturel
- Amélioration de l'accessibilité
- Réduction du temps de chargement des pages
